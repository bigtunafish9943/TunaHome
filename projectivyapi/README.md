# Projectivy wallpaper plugin API

Copied unchanged from Projectivy Launcher's public plugin sample,
https://github.com/spocky/projectivy-plugin-wallpaper-provider (`api` folder),
Apache License 2.0 (see LICENSE in this folder).

TunaHome uses it to talk to wallpaper apps that offer a Projectivy wallpaper
plugin, such as Aerial Views. It must stay byte-for-byte compatible with that
API: wallpaper apps are built against the same files.
